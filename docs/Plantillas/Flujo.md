# Nombre del flujo

Para qué sirve, en una o dos frases.

- Archivo: `flujos/<id>.json`
- Disparador: webhook, horario o manual
- Credenciales: nombre y tipo de cada una, sin valores
- Toca: qué sistemas lee o cambia

## Cómo se comprueba

La URL, el comando o el dato que muestra que funciona.
